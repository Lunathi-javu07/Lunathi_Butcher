The website built using HTML, CSS, and JavaScript.
It shows simple website structure, styling, and useful information of the Butcher business.

## Features

    HTML applied for the structure of the pages 

    Fully responsive website for mobile, tablet, and desktop devices

    Navigation menu with linked pages and hamburger toggle on mobile

    Simple CSS styling with media queries

    "Home","About","Inquiry", "Service"and "Menu" sections

    Google Fonts applied (Playfair Display & Inter)
    
    JavaScript form validation and interactive menu filtering

## Responsive Breakpoints

    Mobile (320px – 767px):
      - Single-column layout
      - 2x2 grid for features
      - Hamburger menu navigation
      - Optimized padding (12px–16px)
      - Hero media hidden on very small screens

    Tablet (768px – 1024px):
      - 3-column grid for features
      - 3-column menu grid
      - Full navigation visible
      - Optimized padding (20px)
      - 2-column footer

    Desktop (1025px+):
      - Full 4-column grids
      - Maximum width container (1200px)
      - Standard spacing and padding (24px–28px)
      - Hamburger menu hidden
      - Responsive images with srcset for 320px/678px/1200px
